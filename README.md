# 🌍 WanderLust – Travel Listing & Booking Platform

WanderLust is a full-stack travel accommodation platform inspired by Airbnb, where users can discover, list, and manage vacation properties. The application provides a seamless booking experience with secure authentication, image uploads, reviews, interactive maps, and responsive design.

---

# 🚀 Features

## 🏡 Property Listings
- Browse all travel accommodations
- View detailed property information
- Search listings by location or title
- Filter listings by category
- Responsive listing cards

## 👤 User Authentication
- Secure user registration and login
- Session-based authentication
- Authorization for protected actions
- Personalized user experience

## ✍️ Listing Management
- Create new property listings
- Edit existing listings
- Delete listings
- Upload property images
- Manage personal listings

## ⭐ Reviews & Ratings
- Add reviews for listings
- Give star ratings
- Delete your own reviews
- View community feedback

## ☁️ Cloud Storage
- Cloudinary image uploads
- Optimized image delivery
- Secure media management

## 🗺️ Maps & Location
- Interactive property location maps
- Display listing locations
- Better travel exploration

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/hitakshi13/wanderlust.git
```

## Navigate to the Project

```bash
cd wanderlust
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create a `.env` file in the project root.

```env
MONGO_URL=

CLOUDINARY_CLOUD_NAME=
CLOUDINARY_KEY=
CLOUDINARY_SECRET=

MAPBOX_TOKEN=

SECRET=
```

## Start the Development Server

```bash
npm start
```

Visit:

```
http://localhost:8080
```
